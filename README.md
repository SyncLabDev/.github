# SyncLabDev/.github

This repository holds the SYNC Lab organization's default community health files and its public profile.

- **Organization profile:** [`profile/README.md`](profile/README.md) renders on [github.com/SyncLabDev](https://github.com/SyncLabDev).
- **Org-wide defaults:** `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and `SECURITY.md` apply to every SYNC Lab repository that does not define its own.

## Repository Conventions

- Repository and FiveM resource names use lowercase snake_case: `sync_notify`, `sync_textui`
- Commercial product names use title case: `SYNC Notify`, `SYNC TextUI`
- Versions live in Git tags — never in repository names
- Paid source code is private by default
